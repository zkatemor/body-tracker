# body-tracker

Личный трекер тела: вес, состав тела (биоимпеданс), объёмы, питание и тренировки.

Сайт: https://zkatemor.github.io/body-tracker/

Данные: [замеры сантиметром](https://docs.google.com/spreadsheets/d/1mLTbE53vwJ1VL-9ManBTwdSsbVKpNzFgciY4COAL1OY/edit) (с апреля 2025), тесты Accuniq BC380, дневник FatSecret.
Весь сайт — один файл `index.html` без сборки.
